# Yazi packaging

The initial PKGBUILD is an unmodified copy of the official
Arch Linux Yazi packaging recipe.

- Upstream: https://github.com/sxyazi/yazi
- Arch packaging: https://gitlab.archlinux.org/archlinux/packaging/packages/yazi
- Arch packaging revision: f3915012b63c8f06eaa73f3d6166f09c16860a4d
- Initial package version: 26.9.1-2
- Initial upstream tag: v26.9.1
- Software license: MIT
- Arch packaging license: 0BSD

Original packaging attribution is retained in PKGBUILD.
The Arch packaging license is included in LICENSE.packaging.

Future source selections update the pinned version, release
number and upstream source checksum through the shared
package candidate review process.

No custom upstream fork is maintained.
